# 09 依赖说明

## 运行环境

实测环境为 Windows + Python 3.13.14。核心链路只依赖 Python 标准库和 openpyxl，
不需要 pandas、scipy、pytest、ortools、reportlab，也不需要前端构建工具。
看板是单页静态 HTML + 内联 JS + SVG，离线双击可开，不引入 Node 或 Vite。

| 包 | 版本 | 必需性 | 用途 | 缺失时的处理 |
|---|---|---|---|---|
| Python 标准库 | 3.13.14 | 必需 | csv、json、datetime、argparse、hashlib、heapq、collections、math、logging、time、pathlib、decimal、unittest、random、tempfile、shutil | 无 |
| openpyxl | 3.1.5 | 必需 | 只读解析两个 xlsx（`read_only=True, data_only=True`） | 报 DataFileError（退出码 2），运行说明里给安装命令 |
| numpy | 2.5.4 | 可选 | 规模曲线的统计拟合 | 本项目的曲线只画实测点，不做拟合；缺 numpy 不影响任何产出 |
| matplotlib | 3.11.2 | 可选 | 画 `results/figures/` 下四张规模曲线 PNG | 自动降级成静态 SVG（纯字符串生成），再不行只剩 `scale_experiments.csv` 数据表；状态写 `curve_status.json` |
| fpdf2 | 2.9.0 | 可选 | 生成 `results/方案报告.pdf` | 走三级降级链，状态写进 `build_manifest.json` |
| fontTools | 随 fpdf2 安装 | 可选 | 运行时只用于核对字体 cmap；PDF 实际用纯 TTF | 不参与生成链路 |

`requirements.txt` 里的版本是实测可运行的精确版本；fpdf2 用
`python -c "import fpdf; print(fpdf.__version__)"` 查得 2.9.0。

明确不引入：pytest、pandas、scipy、ortools、reportlab。自检与单元测试一律用
标准库 `unittest`；核心算法不依赖求解器或数据框。

## 安装

```
python -m pip install -r requirements.txt
```

只跑核心链路时最少只需：

```
python -m pip install openpyxl==3.1.5
```

## 中文字体

按主理人拍板，PDF 优先用已实测可用的纯 TTF `C:\Windows\Fonts\simhei.ttf`，
不强行走 `.ttc` 字体集合解析。`report/build_pdf.py` 的候选顺序是
`simhei.ttf` → `msyh.ttf` → `simsun.ttc` → `msyh.ttc`，
找到第一个存在的文件就用；全部找不到时不做任何假装，走 HTML 降级并在
`build_manifest.json` 里如实记录原因。

实测 `simhei.ttf` 能正常输出中文，但缺上标字符 `³`，也缺数学减号 U+2212、
小于等于号 U+2264 等字形，fpdf2 会打印 missing glyphs 告警。
因此报告正文一律写「立方米」或 `m3`，不写 `m³`；`build_pdf.py` 的
`_safe_text` 在渲染前把这些字符统一换成黑体覆盖得到的 ASCII 写法
（`³` → `3`、`−` → `-`、`≤` → `<=` 等）。只有 Excel 表头 `密度(kg/m³)`
作为数据列名必须原样匹配，这属于列名不是正文，代码里按原样使用。

PDF 实测状态：fpdf2 2.9.0 + simhei.ttf，9 页，前 2 页为《作品说明单》，
一般不超过 10 页；页数与字体名由 `pdf.page_no()` 记录进 manifest。

## 三级降级链

1. fpdf2 与中文字体都可用 → 生成 `results/方案报告.pdf`，manifest 记录字体名、
   实际页数、前 2 页为作品说明单、是否在 10 页以内。
2. 否则生成 `results/方案报告.html`，自带 `@page` 与 `page-break-after` 打印
   样式，页面顶部写明「PDF 未自动生成」及原因；manifest 同样明确写出。
3. 连 HTML 都写不出（磁盘不可写等）→ 只保留 `docs/10_方案报告.md` 内容源，
   manifest 记录失败原因，`10`/`08` 文档里如实说明。

看板与曲线各有自己的降级链（模板缺失给带提示的页面、matplotlib 缺失给静态
SVG），状态同样写进 `build_manifest.json` 与 `results/figures/curve_status.json`。
每级状态都如实记录，绝不假装已生成。
